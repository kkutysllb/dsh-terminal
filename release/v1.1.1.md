# @kkutysllb/dsh-terminal 1.1.1

## 变更

- **node-pty 显式声明于 dependencies（`^1.1.0`）**：dsh 0.1.6-alpha.2 起依赖解析默认运行时模式，且共享保留区（`profiles/node_modules`）被排除——未声明的提升副本不再可解析，声明依赖是唯一稳定入口。版本契约与 DSH core（`@deepseek-ai/dsh-subprocess-local`）同 range：同 range 同 integrity 让 pnpm 两侧解析到同一物理包（一份 native 绑定，无漂移）。
- **修复命令升级**：deps 降级卡的修复命令从 `dsh plugin --profile <name> install` 改为 `dsh plugin --profile <name> add @kkutysllb/dsh-terminal@latest`（指定包重装，语义更精确）。
- README 同步 node-pty 版本契约与解析策略说明。

## 安装

```bash
# DSH 宿主
dsh plugin --profile web add @kkutysllb/dsh-terminal

# QiLin 宿主（QiLin 3.0.2+，双通道 manifest 原生键）
qilin plugin --profile qilin add @kkutysllb/dsh-terminal
```
