# @kkutysllb/dsh-terminal 1.2.0

## 变更

- **原生 dsh 桌面端/Web 端开关按钮适配（本次第二主题）**：按钮注入此前只认 KCoder 桌面壳主进程注入的 `#__dsh_desktop_titlebar`——原生壳没有该元素，按钮永不出现（用户侧表现为「右上角终端按钮不显示/疑似被遮挡」）。现改为锚点链：KCoder 标题栏优先，缺失时回退注入上游会话头右上角动作区 `[data-slot="conversation.session.header.corner"]`（slot 工具化 DOM，键随 ui-conversation 源码稳定；另有非哈希 `data-conversation-header-corner` 兜底选择器）。corner 内按钮 28px 对齐邻居 icon 按钮、`-webkit-app-region:no-drag`（头行整体是拖拽区）、颜色 `currentColor` 随头行主题；样式经 `.kt-corner` 类走样式表（hover/`data-open` 高亮与标题栏形态共用规则，`:not(.kt-corner)` 隔离标题栏专用的 absolute 定位）。会话头仅会话页渲染，hero/设置页无 corner → 按钮随路由消失属预期，5s 常驻巡逻在锚点恢复后重建。
- **dsh 0.2.0 兼容声明（本次主题）**：manifest 按新代插件约定补齐兼容面，供 plugin-manager 安装前检查与 app-boot 启动准入评估（两处共用同一检查器：只看 `@deepseek-ai/dsh` / `@deepseek-ai/dsh-*` 前缀 peer，`includePrerelease: true` 语义）：
  - `dsh.manifestVersion: 1`；
  - `peerDependencies`：`@deepseek-ai/dsh` 与 `@deepseek-ai/dsh-host-webserver`（插件绑定的 webServer 服务所在包）声明 `>=0.1.6-alpha.2 <0.2.0`——semver 里 `0.2.0-rc.* < 0.2.0`，该范围同时命中 0.1.6-alpha.2（v1.1.x 适配基线）与 0.2.0-rc.2；dsh 发 0.2.0 正式版时失配，属有意的评审闸门；
  - `engines`：`node >=20` + `dsh` 同 peer 范围（声明性文档，当前无读取方强制）。
- 服务半功能层零改动（entry.js / cordis.patch.yml 原样）。0.2.0-rc.2（KCoder 桌面 2026-10 实机 + 原生壳同源组合隔离复现）实测全链路通过——cordis 挂载、`/dsh-terminal/api/*`、node-pty 运行时共享区解析（1.2.0-beta.15 + prebuilt spawn-helper）、真实 spawn/写入/回放/关标签、client 物化与面板几何、工作区探针（AppFrame `sidebarCol`/`centerCol`/`data-rightbar-col` 与 `SessionSummary` 契约均未变）；原生壳形态下按钮注入 + 面板开合 + 键盘 IO 实测通过。
- README 新增「dsh 0.2.0 兼容声明」章节、按钮锚点链说明，并补两种实装形态的 node-pty 解析路径说明（pnpm 安装形态落 profile 根 / KCoder 物化形态走运行时共享区）。
- smoke 冒烟扩展：锁定 `manifestVersion`、peer 范围与 `engines` 声明，防形态回退。

## 安装

```bash
# DSH 宿主
dsh plugin --profile web add @kkutysllb/dsh-terminal

# QiLin 宿主（QiLin 3.0.2+，双通道 manifest 原生键）
qilin plugin --profile qilin add @kkutysllb/dsh-terminal
```
