# @kkutysllb/dsh-terminal 1.2.0

## 变更

- **dsh 0.2.0 兼容声明（本次主题）**：manifest 按新代插件约定补齐兼容面，供 plugin-manager 安装前检查与 app-boot 启动准入评估（两处共用同一检查器：只看 `@deepseek-ai/dsh` / `@deepseek-ai/dsh-*` 前缀 peer，`includePrerelease: true` 语义）：
  - `dsh.manifestVersion: 1`；
  - `peerDependencies`：`@deepseek-ai/dsh` 与 `@deepseek-ai/dsh-host-webserver`（插件绑定的 webServer 服务所在包）声明 `>=0.1.6-alpha.2 <0.2.0`——semver 里 `0.2.0-rc.* < 0.2.0`，该范围同时命中 0.1.6-alpha.2（v1.1.x 适配基线）与 0.2.0-rc.2；dsh 发 0.2.0 正式版时失配，属有意的评审闸门；
  - `engines`：`node >=20` + `dsh` 同 peer 范围（声明性文档，当前无读取方强制）。
- 功能层零改动：entry.js / client.js / cordis.patch.yml 原样。0.2.0-rc.2（KCoder 桌面 2026-10 实机）实测全链路通过——cordis 挂载、`/dsh-terminal/api/*`、node-pty 运行时共享区解析（1.2.0-beta.15 + prebuilt spawn-helper）、真实 spawn/写入/回放/关标签、client 物化与面板几何、工作区探针（AppFrame `sidebarCol`/`centerCol`/`data-rightbar-col` 与 `SessionSummary` 契约均未变）。
- README 新增「dsh 0.2.0 兼容声明」章节，并补两种实装形态的 node-pty 解析路径说明（pnpm 安装形态落 profile 根 / KCoder 物化形态走运行时共享区）。
- smoke 冒烟扩展：锁定 `manifestVersion`、peer 范围与 `engines` 声明，防形态回退。

## 安装

```bash
# DSH 宿主
dsh plugin --profile web add @kkutysllb/dsh-terminal

# QiLin 宿主（QiLin 3.0.2+，双通道 manifest 原生键）
qilin plugin --profile qilin add @kkutysllb/dsh-terminal
```
